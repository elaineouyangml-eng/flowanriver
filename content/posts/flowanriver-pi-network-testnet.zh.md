今天想和大家分享一个关于 Flowanriver 的新消息：**Flowanriver 已经接入 Pi Network 的测试环境，正式开始参与生态应用建设。**

目前，Flowanriver 仍处于 Testnet 测试阶段，Pi 登录授权和部分页面兼容性问题还需要继续完善。虽然距离成熟的应用还有一些工作要做，但我还是想记录这个进展，也邀请感兴趣的读者一起来体验。

**访问 Flowanriver：**

- [Flowanriver 官方网站](https://flowanriver.com/)
- [Flowanriver on Pi Browser（Testnet）](https://flowanriverhubhh6610.pinet.com/)

从最初分享 AI、Crypto、商业和生活观察的独立网站，到今天尝试进入 Pi Network 生态，Flowanriver 正在朝着我希望的方向发生变化。

![Flowanriver Hub 已通过 Pi App Studio 发布至 Pi Network Testnet 的页面截图，展示应用访问入口和网站预览。](/images/flowanriver-pi-network-testnet-app-studio-published.png "Flowanriver Hub Published on Pi Network Testnet")

## 生态建设，需要更多人的参与

前段时间，我曾在 [《Pi Network: Seven Years from Its Original Vision》](https://flowanriver.com/posts/pi-network-seven-years-original-vision/) 一文中，回顾 Pi Network 七年来的发展，并讨论它的生态建设与未来方向。当时，我主要站在观察者的角度看待这些问题。没想到不久之后，我也开始尝试让 Flowanriver 参与其中。

关注 Crypto 这些年，我一直在思考：除了数字资产交易，区块链技术还能为普通人的生活带来什么？

一个区块链网络能够发展到什么程度，除了技术架构和用户规模，还取决于是否拥有真正满足需求的应用，以及用户是否愿意持续使用。

Pi Network 的生态建设同样需要这样的过程。

项目方可以提供网络基础设施、开发工具和技术支持，具体的应用则需要开发者、企业、内容创作者和其他参与者共同建设。每个人拥有的经验和能力不同，能够提供的产品与服务自然也不一样。

根据 [Pi Network 官方开发者资料](https://minepi.com/developers/)，开发者可以使用 Pi SDK 等工具，将 Web 应用与 Pi 平台连接，并通过 Pi Browser 为用户提供服务。

我希望未来的 Pi 生态能够涵盖更多类型的应用。除了购物、支付和游戏，资讯、教育、文化以及日常生活服务，同样值得发展。人们使用互联网有各种各样的需求，一个生态也应该容纳不同的产品和服务。

Flowanriver 已经拥有独立网站和自己的内容体系，因此我更愿意从现有的网站出发，尝试参与其中。

至于这次接入能够带来什么，还需要通过后续使用来了解。但比起一直讨论生态应该如何发展，我也想亲自动手试试看。

## 一个编程门外汉，借助 AI 尝试开发

其实，这并不是我第一次创建 Pi 应用。

之前，我曾使用 Pi App Studio 建立过一个简单的 Chatbot。由于缺乏专业编程知识，加上遇到了一些技术问题，最终没有继续完善。

后来，我了解到 Pi App Studio 开始支持借助外部 AI 编程工具开发和接入应用。根据 [Pi Network 的官方介绍](https://minepi.com/blog/vibe-code-app-studio/)，创作者可以使用 AI 编程工具构建应用，再通过相关流程完成 Pi 平台集成。

看到这个消息，我就想，既然 Flowanriver 已经是一个正常运行的网站，为什么不试着让它也进入 Pi 生态？

虽然最初建立 Flowanriver 时，我就使用过 AI，但直到现在，我依然算不上懂编程。面对复杂的代码，经常需要先弄明白它们的作用，再决定从哪里修改。

最近，我一直在调整 Flowanriver 的页面设计，包括导航菜单、配色和不同设备上的布局。有时候只是想移动一个按钮，结果却让其他元素也跟着错位。电脑端刚调整好，换到手机上又出现新的问题，只能重新检查代码。

与此同时，我也开始为网站增加中文支持。

Flowanriver 从建立之初就以英文内容为主，希望能够面向全球读者。随着文章逐渐增加，我也希望中文读者能够更方便地访问网站。

原本以为增加一个语言切换入口就可以了，实际操作后才发现，还需要考虑文章分类、导航菜单、中英文页面链接以及后续内容管理。对于我这样的门外汉来说，这些问题经常需要反复尝试才能找到合适的解决办法。

AI 在这个过程中帮了我不少忙。我可以告诉它自己希望实现什么功能，让它协助检查代码、分析问题，再根据实际效果继续修改。有时建议能够解决问题，有时反而会出现新的错误，甚至需要把之前的改动撤回重来。

这让我想起过去在 Flowanriver 分享 AI 时，经常讨论的一个话题：AI 究竟能够为普通人的工作带来什么？

网络上有很多关于 AI 的宣传，似乎掌握几个工具，就能够轻松开发软件、建立网站，甚至获得可观的收入。但实际操作之后，我更加确定，工具确实能够提供帮助，想法能否实现，仍然需要使用者投入时间、作出判断，并承担最终的结果。

Flowanriver 应该采用什么样的设计、增加哪些功能、面向哪些读者，以及未来如何发展，这些都需要我自己决定。AI 帮我解决了一部分技术上的困难，也让我有机会尝试过去不知道如何着手的事情。

从最初建立网站，到今天调整中文板块、连接 Pi Network，我也算是把以前文章里讨论过的 AI 应用，真正用在了自己的项目上。

## Flowanriver 的未来，不只有资讯与知识分享

Flowanriver 最初只是一个让我自由分享知识、资讯和个人观点的网站，但我从来没有打算将它的发展限定在这里。

随着网站内容逐渐积累，我也开始思考它未来还可以做些什么。除了文章，是否能够提供其他服务？现有的内容和经验，又能否与新的项目结合起来？

关于这些问题，我已经有了一些计划，只是现在还没有到适合公布具体内容的时候。有些想法需要进一步完善，有些则需要更多准备。我希望等到相关工作真正开始落实，再和大家分享。

现阶段，资讯与知识分享依然是 Flowanriver 的重要组成部分。我会继续写自己感兴趣的 AI、Crypto、商业、文化和生活话题，也会根据网站的发展情况，考虑增加其他功能。

这次接入 Pi Network，是 Flowanriver 发展计划中的一次尝试。我希望了解 Web3 能够为现有网站带来怎样的帮助，同时也保留自己的判断，不会因为参与了某个生态，就认为它的每一项技术和应用都一定能够成功。

未来无论增加什么功能，Flowanriver 仍然会保持独立运营，面向所有读者。大家可以继续通过原有网站阅读公开内容，使用 Pi Browser 的用户也可以通过新的入口访问测试版本。

## 欢迎给 Flowanriver 提出建议

目前，Flowanriver 还有不少需要调整的地方，包括页面设计、中文板块、Pi 登录授权以及浏览器兼容性等问题。

我虽然有自己的想法，但一个人考虑问题难免会有遗漏。有时候自己觉得方便的设计，换一个使用者的角度，可能就会发现不同的问题。

所以，我也希望能够听听大家的意见。

无论是文章内容、页面布局、中文阅读体验，还是未来希望增加的功能，都欢迎提出建议。如果你通过 Pi Browser 访问测试版本时遇到登录失败、链接无法打开或页面显示异常等情况，也可以告诉我具体的问题。

我不一定能够立即实现每一个建议，但会认真考虑大家的反馈，看看哪些地方还需要调整。

Flowanriver 从最初的独立博客走到今天，许多改变都是在一次次操作中慢慢完成的。这次进入 Pi Testnet，让我有机会亲自参与生态应用建设，也让我更清楚地认识到，一个想法从开始尝试到真正做好，中间还有不少工作需要完成。

如果你愿意，不妨访问一下 Flowanriver，看看它现在的样子，也告诉我你希望它未来有哪些改变。
